Head Coach Quick Start

Set up your divisions and teams, then prepare and share each week's match. Parent coaches only need Match Day and any lineup permissions you assign.

  1. Create divisions and teams (Orange Ball, Green Ball, etc.).
  2. Add athletes and assign parent coaches to each team. Choose which coaches may create, edit or publish lineups.
  3. Plan a match: choose the division, team, date, opponent, format, start time and location, then set and save the lineup.
  4. Use Share Lineup by Text to share match details, optional Snacks/Drinks and the 30-minute warm-up reminder.
  5. On match day, open Match Day, choose the scorecard and load the saved lineup by date.

Cloud access is still in development. This version stores data on the local device. Secure coach invitations, synchronized permissions and automatic updates to other phones are not active. Sending a lineup text does not grant app access.
